# 影院管理系统后端

这是大四上学期生产实习的实训项目

## 目录结构

- **consumer/**: 该目录存放所有 consumer 调用接口。
- **eureka_server/**: eureka 注册中心。
- **service_movie/**: 影片、影院相关接口模块。
- **service_user/**: 用户相关接口模块。
- **README.md**: 当前文件，描述整个项目结构和内容。
